## About Me

I am an aspiring **Data Engineer** interested in building systems that transform raw data into reliable and usable data products.

Rather than simply learning how to use technologies, I focus on understanding their underlying principles, trade-offs, failure modes, and operational behavior.

My current interests include:

* Distributed data processing
* Streaming and batch pipelines
* Data lakehouse architecture
* Data quality and governance
* Cloud-native data platforms
* Reliable AI and machine learning data infrastructure

> Technologies change, but engineering fundamentals remain.

## How I Study Engineering

I aim to understand not only **how a system works**, but also:

* Why it was designed that way
* What trade-offs it makes
* How it fails
* How it recovers
* How it behaves under load
* How it should be operated in production
